# IPWEB 代理使用指南

## 一、如何获取动态住宅代理？

本章介绍 IPWeb 动态代理的基础购买与使用流程，包括 **流量充值、获取代理、查看流量历史和充值记录** 三个部分。

### 1.1 流量充值

登录 IPWeb 用户后台后，在左侧导航栏进入 **代理产品 \> 动态代理**，默认进入 **流量充值** 页面。

#### 步骤 1：选择并购买流量

在「流量充值」页面可以查看当前流量套餐的计费规则。

- 流量单价：按 GB 计费；

- 用量越大，单价越低；

- 可自定义流量包。

点击购买适合您的流量套餐。

![流量充值界面](https://oss.ipweb.cc/docs/imgs/2026/08/dynamic-traffic-recharge.png)

#### 步骤 2：确认订单并完成支付

进入「订单确认」页面后，可再次查看本次购买的详细信息，包括：

- 单价

- 流量

- 金额

确认订单信息无误后，选择可用的支付方式。

![流量充值支付](https://oss.ipweb.cc/docs/imgs/2026/08/dynamic-order-confirmation.png)

页面支持的支付方式包括：

- **钱包余额**

- **银联**

- **USDT（TRC2\.0）**

- **支付宝（香港）**

- **支付宝**

- **信用卡支付**

- **PayPal**


选择支付方式后，点击 **「支付」**，按照页面提示完成付款。



支付成功后，对应流量将按照订单规则计入动态代理账户，可用于后续生成和使用代理。

> **注意：** 实际可用支付方式可能因账户、地区或后台配置不同而有所变化，请以支付页面显示为准。
> 
> 

### 1.2 获取代理

流量充值完成后，进入 **代理产品 \> 动态代理 \> 获取代理**，即可根据使用需求生成代理连接信息。

![获取代理](https://oss.ipweb.cc/docs/imgs/2026/08/dynamic-get-proxy.png)

#### 步骤 1：设置代理地区

在「生成代理配置」区域选择代理出口位置。

页面支持按以下层级进行地区筛选：

- **国家/地区**

- **州**

- **城市**

如不需要精确到州或城市，可根据实际业务需求选择相应的定位范围。

> 地区选项决定代理出口 IP 的目标地理位置。实际可选国家、州和城市以后台当前可用资源为准。
> 
> 

#### 步骤 2：确认代理协议

当前页面显示代理同时支持：

- **HTTP**

- **HTTPS**

- **SOCKS5**

生成代理时无需单独切换协议，实际接入时可根据客户端、浏览器或程序所支持的代理协议进行配置。

#### 步骤 3：选择代理服务器和 IP 持续时间

继续设置以下参数：

- **代理服务器**：选择用于接入动态代理网络的代理服务器节点。

- **IP 持续时间**：设置当前代理会话中出口 IP 的有效时长，单位以后台页面显示为准。

IP 持续时间用于控制动态代理 IP 在当前配置下保持的时间。达到设置时长后，代理出口 IP 可根据服务机制进行轮换。

> IP 持续时间不等同于静态代理。动态代理仍属于动态 IP 资源，具体 IP 保持与切换逻辑以后台实际服务规则为准。
> 
> 

#### 步骤 4：设置代理数量

在 **「代理数量」** 中输入需要生成的代理条数。

页面显示单次最多可生成 **1000 条**代理。

请根据实际使用规模设置数量，避免一次生成大量暂时不使用的代理配置。

#### 步骤 5：生成代理

完成地区、代理服务器、IP 持续时间和代理数量设置后，点击：

- **「生成代理」**：生成可直接用于代理客户端或程序配置的代理信息；

- **「生成二维码」**：以二维码形式生成对应配置，适用于支持扫码导入的场景。

如需重新设置参数，可点击 **「重置」**。

页面下方还提供代理密码管理功能。如需更换当前代理认证密码，可点击 **「修改代理密码」**。

> **安全提示：** 代理账号和密码属于认证凭据，请妥善保管，不要公开分享。修改代理密码后，原先保存于浏览器、代理软件或程序中的认证信息也需要同步更新。
> 
> 

### 1.3 查看流量历史和充值记录

IPWeb 后台分别提供 **流量历史** 和 **充值历史**，用于查询动态代理的流量消耗情况以及账户流量变更记录。

#### 查看流量历史

进入 **代理产品 \> 动态代理 \> 流量历史**。

在查询区域可以通过以下条件筛选记录：

- **开始/结束时间**

- **用户名称**

- **代理账号**

设置查询条件后，点击 **「搜索」**；如需清除当前筛选条件，可点击 **「重置」**。

![查看流量历史](https://oss.ipweb.cc/docs/imgs/2026/08/dynamic-traffic-history.png)

流量历史列表主要显示：

- **日期**

- **用户名称**

- **已用总流量**

- **上行流量**

- **下行流量**

其中：

- **上行流量**：通过代理连接从客户端发送到代理网络的数据量；

- **下行流量**：通过代理连接从代理网络返回到客户端的数据量；

- **已用总流量**：当前记录对应的整体流量使用情况。

通过流量历史，可以按日期、用户或代理账号核对动态代理的流量消耗。

#### 查看充值记录

进入 **代理产品 \> 动态代理 \> 充值历史**。

页面支持通过以下条件查询充值或流量变更记录：

- **用户名称**

- **类型**

- **充值来源用户名**

- **记录 ID**

- **订单号**

输入查询条件后，点击 **「搜索」**；如需重新查询，可点击 **「重置」**。

![查看充值历史](https://oss.ipweb.cc/docs/imgs/2026/08/dynamic-recharge-history.png)

充值历史列表会显示相应的记录信息，包括：

- **ID**

- **用户名称**

- **类型**

- **操作来源**

- **流量数**

- **创建时间**

- **订单号**

通过该页面可以核对流量充值、系统变更等相关记录，并结合订单号查询具体充值情况。

> **提示：** 如果发现账户剩余流量与预期不一致，可以先结合「流量历史」核对实际消耗，再通过「充值历史」确认最近的流量充值或变更记录。

## 二、导出的代理各项内容代表什么？

第一步的操作完成之后，打开下载的 txt 文件，显示的内容就是一些代理的信息。

IPWEB 严格依据 SOCKS5/HTTP 代理协议，Socks5/HTTP 代理（账号密码模式）格式如下：

```
代理服务器(IP/域名):端口:代理账号:密码
```

有些代理 IP 的同行也会提供这种排列方式：

```
代理账号:密码:代理服务器(IP/域名):端口
```

### 示例说明

**示例代理信息：**

```
gate1.ipweb.cc:7778:B_36307_US_1474_10748_5_Ab000001:123456
```

**各项内容解析：**

- **代理服务器**：`gate1.ipweb.cc`
- **代理服务器端口**：`7778`
- **用户编号**：`B_36307`
- **国家代码**：`US`
- **州代码**：`1474`
- **城市代码**：`10748`
- **IP 持续时间**（单位：分钟）：`5`
- **SID**：`Ab000001`
- **代理密码**：`123456`
- **代理协议**：同时支持 socks5/http(s)，不需修改端口

### 图文说明

![代理信息结构说明图](https://oss.ipweb.cc/docs/imgs/503010952dd7970.png)

### 验证代理有效性

让我们验证一下上面导出的这条 IP 是否有效。我们可以通过 curl 命令来验证：

```bash
curl -x B_36424_US_1474_10748_5_Ab000001:123456@gate1.ipweb.cc:7778 ipinfo.io
```

![curl 验证结果](https://oss.ipweb.cc/docs/imgs/71f9b316d82b791.png)

我们通过执行 curl 命令，成功获取到一条来自美国 US（国家代码：US）纽约州 New York（州代码：1474）纽约城市 New York City（城市代码：10748）的代理 IP。

## 三、如何使用"自编代理账号"生成代理？

"自编代理账号"是指按照 IPWEB 的规则手动或者程序生成代理账号的方式。通过这种方式，您可以灵活地生成所需的代理信息。

### 1. 修改国家、州和城市代码

按照上面的示例，更改国家代码、州代码及地区代码，就可以生成其他您想要的代理 IP。当然，其中州代码和地区代码可以不填，例如：

```
gate1.ipweb.cc:7778:B_36424_US___5_Ab000001:123456
```

因为这两项并非必填项，如果州代码及地区代码您不填，这表示您要获取一条美国的代理 IP（且不限制州和地区）。

**如何查询国家代码、州代码及地区代码？**

登录 IPWEB 后台 <IpwebLoginLink lang="zh" />，在"获取代理"下方点击"导出地区城市编码"，下载可查询全球 200 多个国家近 20000 个城市对应的代码。

![国家地区城市编码查询](https://oss.ipweb.cc/docs/imgs/2026/08/export-region-city-code.png)

### 2. 修改国家代码和 IP 持续时间

以上述代理 IP 为例：

```
gate1.ipweb.cc:7778:B_36424_US___5_Ab000001:123456
```

假设需要获取一条香港的代理 IP，则将上述中的"US"更改为"HK"，更改后完整代理 IP 信息如下：

```
gate1.ipweb.cc:7778:B_36424_HK___5_Ab000001:123456
```

同样，如果我们希望代理 IP 有效时长想从原来的 5 分钟调整至 10 分钟，则将上述中的"5"变更为"10"，更改后的完整代理 IP 信息如下：

```
gate1.ipweb.cc:7778:B_36424_HK___10_Ab000001:123456
```

### 3. 如何根据 IPWEB 的自编代理规则生成多条代理？

以这条 IP 为例：

```
gate1.ipweb.cc:7778:B_36424_US_1474_10748_5_Ab000001:123456
```

我们需要更改 SID 就可以变化 IP。利用这一点，我们可以利用 IPWEB 的自编代理功能生成无限的代理 IP，例如：

```
gate1.ipweb.cc:7778:B_36424_US_1474_10748_5_Ab000001:123456
gate1.ipweb.cc:7778:B_36424_US_1474_10748_5_Ab000002:123456
gate1.ipweb.cc:7778:B_36424_US_1474_10748_5_Ab000003:123456
...
gate1.ipweb.cc:7778:B_36424_US_1474_10748_5_X9999999:123456
```

> **注意**：SID 随机码可以修改成任意 8 位字符，大小写字母、数字或其组合都可以（不能包含特殊字符，如"@！%……\*"）。

通过修改 SID，理论上您可以无限生成代理。当然，通过修改 SID，也可以起到切换 IP 地址的效果。

### 4. 如何根据 IPWEB 的代理 IP 自编功能规则生成全球随机代理？

我们在实际使用中，可能需要的代理 IP 并不希望限制某个国家，希望获取的代理 IP 是来自全球任意国家的。IPWEB 称为获取全球随机代理 IP，利用 IPWEB 代理 IP 自编功能可以轻松将它实现。

我们仅仅只需要将国家代码一处填写为"000"，则表示获取的代理 IP 为全球随机代理 IP，示例如下：

```
gate1.ipweb.cc:7778:B_36424_000___10_Ab000001:123456
```

## 四、如何选择代理服务器？

IPWEB 目前在全球三个区域布有大量代理服务器：

1. **美洲区**（南美与北美）：`gate1.ipweb.cc:7778`
2. **亚太地区**（包括大洋洲）：`gate2.ipweb.cc:7778`
3. **欧洲及非洲**：`gate3.ipweb.cc:7778`

根据您自己的业务以及业务服务器所在区域综合考虑选择代理服务器，建议使用 IPWEB 自动分配的代理服务器，这样延迟更低。也可以咨询 IPWEB 技术支持与客服来选择最佳的代理服务器。
