## 基础流程

### 1、注册账号

第一步，打开 IPWeb 官网 `https://ipweb.cc`，点击页面顶部导航栏中的「**注册**」按钮（已有账号的用户可直接点击「**登录**」）。

![IPWeb官网首页](https://oss.ipweb.cc/docs/imgs/2026/07/image1.png)

第二步，在注册页面填写你的**邮箱地址**和**登录密码**；也可以直接使用 **Gmail 账号**快捷注册（推荐），省去额外的密码设置步骤。

![IPWeb注册/登录](https://oss.ipweb.cc/docs/imgs/2026/07/image2.png)

第三步，前往邮箱查收验证邮件，点击邮件中的**确认链接**完成邮箱验证。如果收件箱没有看到邮件，请检查垃圾邮件文件夹。（部分邮箱可能有延迟，耐心等待几分钟即可）

### 2、领取试用流量

注册完成后，首次登录 IPWeb 用户后台 `https://user.ipweb.cc`，联系客服即可获赠 **免费试用流量**，体验全类型代理服务。

> 新用户可以先使用赠送流量测试代理效果，确认满足需求后再选择正式套餐。

### 3、购买代理 IP 套餐

成功登录 IPWeb 后，在左侧仪表盘选择你要购买的动态住宅代理。

动态住宅代理采用**按流量计费、随取随用**的模式，无需提前购买固定套餐，获取代理时即开始计量。

第一步，在用户后台左侧菜单中点击「**获取代理**」按钮。

第二步，设置以下参数：

- **国家 / 地区**：根据业务需求，选择代理 IP 的目标归属地（支持 220+ 国家）
- **代理服务器**：选定国家后，系统会自动为你分配对应的**代理服务器地址**
- **IP 持续时间**：指该 IP 的最长使用时间，时间一到会自动更换 IP。**IP 更换不会导致网络中断**，代理账号一直可用，只是 IP 会变。根据你的业务需求选择合适的持续时间
- **代理数量**：指导出代理账号的数量（比如需要 5 条就填写 5）。单次导出最大不超过 **1000 条**
- **代理协议**：HTTP 或 SOCKS5（根据客户端支持情况选择）

![动态代理参数配置](https://oss.ipweb.cc/docs/imgs/2026/07/image3.png)

第三步，首次生成代理时需要先**设置代理密码**——这个密码就是后续接入客户端时使用的认证密码。需要注意的是：**修改密码后生效时间约 1 分钟**；如果出现代理信息外泄或被盗，请及时修改此密码。

第四步，参数确认无误后点击「**生成代理**」，系统会自动下载一个 **txt 文件**。文件内容就是根据你的选择生成的代理连接信息，每行一条，格式为：

```
代理服务器地址:端口:用户名:密码
```

请妥善保存该文件，后续在 NekoBox 中配置时会用到。

![仪表盘总览](https://oss.ipweb.cc/docs/imgs/2026/07/image5.png)

#### 流量使用记录

点击左侧导航栏「**动态住宅代理**」下的「**流量历史**」，系统会自动生成消耗报表，你可以按特定时间段精确查看流量的具体去向。

![流量历史记录](https://oss.ipweb.cc/docs/imgs/2026/07/image6.png)

#### 充值记录

## NekoBox 配置

本教程针对 **NekoBox** 客户端编写。NekoBox 是一款代理工具，界面简洁直观，支持 SOCKS5 / HTTP 等多种协议，非常适合住宅代理的快速接入。以下步骤均以 **Windows 平台** 为准。

配置前请确保你已经完成了上一节的购买流程，并拿到了代理连接信息（代理服务器地址、端口号、用户名、密码）。同时请确认已安装 [NekoRay](https://github.com/MatsuriDayo/nekoray) 最新版本。

### 1、准备代理连接信息

确认你手上有以下四项信息：

- **代理服务器地址**
- **端口号**
- **用户名**
- **密码**

### 2、添加 IPWeb 代理节点

打开 **NekoBox** 客户端，按以下步骤操作：

#### ① 右键选择「手动输入配置」

启动 NekoBox 后，在主界面的**服务器列表空白区域右键单击**，在弹出的菜单中选择 **「手动输入配置」**。

![NekoBox右键手动输入](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step1.png)

#### ② 填写节点配置信息

在弹出的「**编辑**」窗口中，按如下方式填写：

| 字段 | 填写内容 |
| --- | --- |
| **类型** | 选择 `Socks`（即 SOCKS5 协议） |
| **名称** | `proxy1` 或任意方便识别的名称 |
| **地址** | 你的代理服务器地址 |
| **端口** | 你的端口号（如 `7778`） |

然后在下方的 **Socks** 区域填写认证信息：

| 字段 | 填写内容 |
| --- | --- |
| **版本** | `5`（表示 SOCKS5） |
| **用户名** | 你的代理用户名（如 `B_57164U...`） |
| **密码** | 你的代理密码 |

> ⚠️ 如果你在 IPWeb 后台获取的是 HTTP 协议代理，类型应改为对应 HTTP 选项；SOCKS5 对应选 `Socks`，版本设为 `5`。两者必须与后台一致，否则无法连通。

填写完毕后，点击窗口底部的 **「确定」** 保存节点。

![NekoBox编辑窗口](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step2.png)

### 3、确认节点已添加到列表

保存成功后，回到主界面，你可以在**服务器列表**中看到刚添加的节点信息：类型为 `Socks`，地址和名称均显示正确。

![NekoBox服务器列表](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step3.png)

> 如果你有多条 IPWeb 代理（比如批量导出了多个账号），可以重复第二步的操作逐一添加，后续可在节点间自由切换。

### 4、启动节点并开启系统代理

确认以下两项均已就绪：

1. **开启 Tun 模式和系统代理**：在主界面顶部工具栏中，先勾选 **「Tun 模式」** 和 **「系统代理」** 两个选项（标题栏会出现 `[Tun+系统代理]` 标识）
2. **选中并启动节点**：在服务器列表中**勾选** IPWeb 节点（左侧出现 ✓ 标记），然后**右键该节点 → 选择「启动」**

**启动成功后：**

- 标题栏显示 `[Admin] [Tun+系统代理] NekoBox ... [Socks] proxy1@默认`
- 节点右侧会显示**测试结果和流量数据**（如 `41.54 KiB ↑ | 162.74 KiB ↓`）
- 底部日志区域显示连接活动记录

![NekoBox启动节点](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step4.png)

打开浏览器访问 `https://ipinfo.io` 或其他 IP 检测网站，检查返回的 IP 地址是否为你所选购地区的代理 IP。如果显示正确，说明配置成功。

![IPinfo检测结果示例 — 显示代理IP归属地](https://oss.ipweb.cc/docs/imgs/2026/07/ipinfo-result.png)

> 如果 IP 检测显示的是你本地 IP，请依次排查：
>
> 1. 「Tun 模式」和「系统代理」是否都已勾选
> 2. 服务器列表中的节点是否已勾选并启动
> 3. 节点编辑中的地址、端口、用户名、密码是否与 IPWeb 提供的信息完全一致
> 4. 协议类型（Socks / HTTP）是否与你购买时选择的协议一致

### 5、路由规则分流（可选）

如果你希望只有特定流量走 IPWeb 代理，而其他流量继续走原有节点或直连，可以使用 NekoBox 的**路由规则**功能实现分流。点击顶部菜单栏的 **「设置」**，在 **「路由规则」** 标签页中添加自定义规则，例如：

| 规则示例 | 含义 |
| --- | --- |
| 目标域名 `target-website.com` → 走 IPWeb 节点 | 只有访问该域名的请求走代理 |
| 目标 IP 段 `10.0.0.0/8` → 直连 | 局域网地址不经过代理 |
| 默认 → 直连 / 其他节点 | 其余流量按需路由 |

这样只有匹配规则的流量才会通过 IPWeb 代理发出，其余流量保持原有路径不变。

## 链式代理

如果你在国内网络环境下无法直接连接目标国家或地区的代理服务器，可以在 NekoBox 中配置**链式代理**：先通过一个当前网络可以正常连接的境外前置代理建立通道，再连接目标国家或地区的后置代理。

链路顺序如下：

> **本机 → 前置代理（境外节点）→ 后置代理（目标国家/地区）→ 目标网站**

例如，使用香港代理作为前置代理、美国动态住宅代理作为后置代理。配置成功后，目标网站看到的最终出口应为**美国后置代理 IP**，而不是本地公网 IP 或香港前置代理 IP。

### 1、准备两组代理信息

开始前，请准备好以下两个节点的地址、端口、用户名和密码：

| 节点角色 | 用途 | 示例名称 |
| --- | --- | --- |
| **前置代理** | 负责先将本地流量转发到境外，必须能在当前网络环境下正常连接 | `proxy1-hk` |
| **后置代理** | 连接目标国家或地区，并作为最终业务出口 | `proxy2-us` |

建议选择距离本地较近、延迟较低且稳定的节点作为前置代理；后置代理则根据实际业务所需的国家或地区选择。

> 本节以两个 SOCKS5 节点为例。如果你的节点使用 HTTP 协议，请选择对应的 HTTP 类型，并确保协议与代理服务提供的信息一致。

### 2、添加境外前置代理

在 NekoBox 主界面的服务器列表空白处右键，选择「**手动输入配置**」，然后填写前置代理信息：

| 字段 | 填写内容 |
| --- | --- |
| **类型** | 选择 `Socks` |
| **名称** | 例如 `proxy1-hk` |
| **地址** | 前置代理服务器地址 |
| **端口** | 前置代理端口 |
| **版本** | 选择 `5` |
| **用户名 / 密码** | 前置代理的认证信息 |

填写完成后，点击「**确定**」保存。

![在 NekoBox 中添加境外前置代理](https://oss.ipweb.cc/docs/imgs/nekobox-chain-step1.png)

> 前置代理是整条链路的第一跳。如果该节点无法连接或延迟过高，后置代理也会连接失败。建议保存后先单独测试该节点，确认能够正常使用。

### 3、添加目标国家或地区的后置代理

再次在服务器列表空白处右键，选择「**手动输入配置**」，填写后置代理信息：

| 字段 | 填写内容 |
| --- | --- |
| **类型** | 选择与后置代理一致的协议，本例为 `Socks` |
| **名称** | 例如 `proxy2-us` |
| **地址** | 后置代理服务器地址 |
| **端口** | 后置代理端口 |
| **版本** | SOCKS5 节点选择 `5` |
| **用户名 / 密码** | 后置代理的认证信息 |

填写完成后，点击「**确定**」保存。

![在 NekoBox 中添加目标国家或地区的后置代理](https://oss.ipweb.cc/docs/imgs/nekobox-chain-step2.png)

保存后，服务器列表中应同时显示 `proxy1-hk` 和 `proxy2-us`。建议分别测试两个节点的连接信息，确认地址、端口、协议和账密没有填写错误。

### 4、创建链式代理并设置节点顺序

在服务器列表空白处右键，选择「**手动输入配置**」，按以下步骤创建代理链：

1. 将「**类型**」设置为「**链式代理**」。
2. 将名称填写为 `chain-proxy`，或其他便于识别的名称。
3. 点击「**选择配置**」，将 `proxy1-hk` 和 `proxy2-us` 加入链式代理列表。
4. 检查节点顺序：`proxy1-hk` 位于上方，`proxy2-us` 位于下方。
5. 点击「**确定**」保存链式代理。

![在 NekoBox 中创建链式代理并排列节点顺序](https://oss.ipweb.cc/docs/imgs/nekobox-chain-step3.png)

> ⚠️ NekoBox 的链式代理流量顺序为**从上到下**，并将最后一个配置作为流量出口。因此本例必须保持 `proxy1-hk → proxy2-us` 的顺序。顺序颠倒会导致出口 IP 错误，甚至无法连接。

### 5、启动链式代理

回到 NekoBox 主界面后，按以下步骤启用代理链：

1. 在服务器列表中选中 `chain-proxy`。
2. 右键该条目并选择「**启动**」，确认左侧出现 ✓ 标记。
3. 勾选顶部的「**Tun 模式**」和「**系统代理**」。
4. 观察日志区域是否出现连接记录，并确认链式代理条目开始显示流量数据。

![在 NekoBox 中启动链式代理并开启 Tun 模式和系统代理](https://oss.ipweb.cc/docs/imgs/nekobox-chain-step4.png)

> 需要启动的是 `chain-proxy` 链式代理条目，不是单独启动 `proxy1-hk` 或 `proxy2-us`。NekoBox 会按照链式代理中设置的顺序自动调用两个节点。

### 6、验证最终出口 IP

打开浏览器访问 `https://ipinfo.io` 或其他可信的 IP 检测网站，核对以下信息：

- 显示的 IP 是否与后置代理 IP 一致；
- 国家或地区是否与购买的目标线路一致；
- 显示的是否既不是本地公网 IP，也不是前置代理的出口 IP。

![IPinfo检测结果示例 — 显示代理IP归属地](https://oss.ipweb.cc/docs/imgs/2026/07/ipinfo-result.png)

如果检测结果显示的是 `proxy2-us` 对应的目标 IP，说明链式代理已经配置成功。由于流量比单节点连接多经过一跳，延迟略有增加属于正常现象。

### 7、常见问题排查

| 现象 | 建议检查项 |
| --- | --- |
| 链式代理无法启动 | 分别核对两个节点的地址、端口、协议、用户名和密码，并先单独测试前置代理 |
| 后置代理一直超时 | 确认前置代理在当前网络下可以正常连接，并尝试更换延迟更低、更稳定的境外前置节点 |
| 检测结果是前置代理 IP | 检查链式代理列表是否缺少后置代理，或节点顺序是否写反；正确顺序应为 `proxy1-hk → proxy2-us` |
| 检测结果仍是本地公网 IP | 确认启动的是 `chain-proxy`，并检查「Tun 模式」和「系统代理」是否均已勾选 |
| 连接成功但速度较慢 | 链式代理会增加一跳，建议缩短前置节点距离、选择低延迟线路，并避免叠加不必要的代理层级 |

> 不同 NekoBox 版本的按钮名称或位置可能略有差异，请以当前客户端界面为准。请仅将代理用于合法合规的业务场景，并遵守目标网站的服务条款及当地法律法规。
