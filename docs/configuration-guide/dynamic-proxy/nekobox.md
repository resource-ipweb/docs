## 基础流程

### 1、注册账号

第一步，打开 IPWeb 官网 `https://ipweb.cc`，点击页面顶部导航栏中的「**注册**」按钮（已有账号的用户可直接点击「**登录**」）。

![IPWeb官网首页](https://oss.ipweb.cc/docs/imgs/2026/07/image1.png)

第二步，在注册页面填写你的**邮箱地址**和**登录密码**；也可以直接使用 **Gmail 账号**快捷注册（推荐），省去额外的密码设置步骤。

第三步，前往邮箱查收验证邮件，点击邮件中的**确认链接**完成邮箱验证。如果收件箱没有看到邮件，请检查垃圾邮件文件夹。（部分邮箱可能有延迟，耐心等待几分钟即可）

![IPWeb注册/登录](https://oss.ipweb.cc/docs/imgs/2026/07/image2.png)

### 2、领取试用流量

注册完成后，首次登录 IPWeb 用户后台 `https://user.ipweb.cc`，联系客服即可获赠 **免费试用流量**，体验全类型代理服务。

> 新用户可以先使用赠送流量测试代理效果，确认满足需求后再选择正式套餐。

### 3、购买代理 IP 套餐

成功登录 IPWeb 后，在左侧仪表盘选择你要购买的动态住宅代理。

动态住宅代理采用**按流量计费、随取随用**的模式，无需提前购买固定套餐，获取代理时即开始计量。

第一步，在用户后台左侧菜单中点击「**获取代理**」按钮。

第二步，设置以下参数：

- **国家 / 地区**：根据业务需求，选择代理 IP 的目标归属地（支持 220+ 国家）
- **代理服务器**：选定国家后，系统会自动为你分配对应的**代理服务器地址**
- **IP 持续时间**：指该 IP 的最长使用时间，时间一到会自动更换 IP。**IP 更换不会导致网络中断**，代理账号一直可用，只是 IP 会变。根据你的业务需求选择合适的持续时间
- **代理数量**：指导出代理账号的数量（比如需要 5 条就填写 5）。单次导出最大不超过 **1000 条**
- **代理协议**：HTTP 或 SOCKS5（根据客户端支持情况选择）

![动态代理参数配置](https://oss.ipweb.cc/docs/imgs/2026/07/image3.png)

第三步，首次生成代理时需要先**设置代理密码**——这个密码就是后续接入客户端时使用的认证密码。需要注意的是：**修改密码后生效时间约 1 分钟**；如果出现代理信息外泄或被盗，请及时修改此密码。

第四步，参数确认无误后点击「**生成代理**」，系统会自动下载一个 **txt 文件**。文件内容就是根据你的选择生成的代理连接信息，每行一条，格式为：

```
代理服务器地址:端口:用户名:密码
```

请妥善保存该文件，后续在 NekoBox 中配置时会用到。


### 4、充值与支付

IPWeb 支持以下付款方式：

| 支付方式 | 说明 |
|---------|------|
| 支付宝 (HK) | 港币结算，即时到账 |
| USDT-TRC20 | 加密货币支付 |
| 对公转账 | 企业客户可申请对公打款 |

在后台「**财务管理 > 充值中心**」中选择对应支付方式完成付款。企业客户如有定制化需求，也可直接联系客服获取专属报价方案。

> 动态住宅代理是按流量消耗扣费的，建议在充值后留意流量余量，避免因余额不足导致服务中断。


### 5、查看流量使用情况

购买完成后，你可以随时通过 IPWeb 后台对账户资产和使用数据进行可视化管理。

#### 总览仪表盘

登录后台后默认进入的「**仪表盘**」页面即是数据控制中心，你可以直观看到当前账户的**总余额**以及各产品线的**剩余可用流量**。建议留意流量预警，以便及时充值避免影响业务。

![仪表盘总览](https://oss.ipweb.cc/docs/imgs/2026/07/image5.png)

#### 流量使用记录

点击左侧导航栏「**动态住宅代理**」下的「**流量历史**」，系统会自动生成消耗报表，你可以按特定时间段精确查看流量的具体去向。

![流量历史记录](https://oss.ipweb.cc/docs/imgs/2026/07/image6.png)

#### 充值记录

点击「**动态住宅代理**」下的「**充值历史**」，这里详细记录了每一次为动态代理充值的**时间、单号、金额与状态**，方便财务核对与成本管理。

![充值历史记录](https://oss.ipweb.cc/docs/imgs/2026/07/image8.png)


## NekoBox（Windows）配置 IPWeb 代理 IP

本教程针对 **NekoBox** 客户端编写。NekoBox 是一款基于 **sing-box** 内核的 Windows 代理工具，界面简洁直观，支持 SOCKS5 / HTTP 等多种协议，非常适合住宅代理的快速接入。以下步骤均以 **Windows 平台** 为准。

配置前请确保你已经完成了上一节的购买流程，并拿到了代理连接信息（代理服务器地址、端口号、用户名、密码）。同时请确认已安装 [NekoRay](https://github.com/MatsuriDayo/nekoray) 最新版本。

### 1、准备代理连接信息

确认你手上有以下四项信息：

- **代理服务器地址**
- **端口号**
- **用户名**
- **密码**

> 如果你购买的是**动态住宅代理**，这些信息就在你生成并下载的 txt 文件中；如果是**静态住宅代理**，在「已购线路明细」中查看。  
> 文件格式为：`服务器地址:端口:用户名:密码`，用 `:` 分隔。

### 2、添加 IPWeb 代理节点

打开 **NekoBox** 客户端，按以下步骤操作：

#### ① 右键选择「手动输入配置」

启动 NekoBox 后，在主界面的**服务器列表空白区域右键单击**，在弹出的菜单中选择 **「手动输入配置」**。

![NekoBox右键手动输入](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step1.png)

#### ② 填写节点配置信息

在弹出的「**编辑**」窗口中，按如下方式填写：

| 字段 | 填写内容 |
| --- | --- |
| **类型** | 选择 `Socks`（即 SOCKS5 协议） |
| **名称** | `proxy1` 或任意方便识别的名称 |
| **地址** | 你的代理服务器地址 |
| **端口** | 你的端口号（如 `7778`） |

然后在下方的 **Socks** 区域填写认证信息：

| 字段 | 填写内容 |
| --- | --- |
| **版本** | `5`（表示 SOCKS5） |
| **用户名** | 你的代理用户名（如 `B_57164U...`） |
| **密码** | 你的代理密码 |

> ⚠️ 如果你在 IPWeb 后台获取的是 HTTP 协议代理，类型应改为对应 HTTP 选项；SOCKS5 对应选 `Socks`，版本设为 `5`。两者必须与后台一致，否则无法连通。

填写完毕后，点击窗口底部的 **「确定」** 保存节点。

![NekoBox编辑窗口](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step2.png)

### 3、确认节点已添加到列表

保存成功后，回到主界面，你可以在**服务器列表**中看到刚添加的节点信息：类型为 `Socks`，地址和名称均显示正确。

![NekoBox服务器列表](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step3.png)

> 如果你有多条 IPWeb 代理（比如批量导出了多个账号），可以重复第二步的操作逐一添加，后续可在节点间自由切换。

### 4、启动节点并开启系统代理

确认以下两项均已就绪：

1. **开启 Tun 模式和系统代理**：在主界面顶部工具栏中，先勾选 **「Tun 模式」** 和 **「系统代理」** 两个选项（标题栏会出现 `[Tun+系统代理]` 标识）
2. **选中并启动节点**：在服务器列表中**勾选** IPWeb 节点（左侧出现 ✓ 标记），然后**右键该节点 → 选择「启动」**

**启动成功后：**

- 标题栏显示 `[Admin] [Tun+系统代理] NekoBox ... [Socks] proxy1@默认`
- 节点右侧会显示**测试结果和流量数据**（如 `41.54 KiB ↑ | 162.74 KiB ↓`）
- 底部日志区域显示连接活动记录

![NekoBox启动节点](https://oss.ipweb.cc/docs/imgs/2026/07/nekoray-step4.png)

打开浏览器访问 `https://ipinfo.io` 或其他 IP 检测网站，检查返回的 IP 地址是否为你所选购地区的代理 IP。如果显示正确，说明配置成功。

![IPinfo检测结果示例 — 显示代理IP归属地](https://oss.ipweb.cc/docs/imgs/2026/07/ipinfo-result.png)

> 如果 IP 检测显示的是你本地 IP，请依次排查：
>
> 1. 「Tun 模式」和「系统代理」是否都已勾选
> 2. 服务器列表中的节点是否已勾选并启动
> 3. 节点编辑中的地址、端口、用户名、密码是否与 IPWeb 提供的信息完全一致
> 4. 协议类型（Socks / HTTP）是否与你购买时选择的协议一致

### 5、路由规则分流（可选）

如果你希望只有特定流量走 IPWeb 代理，而其他流量继续走原有节点或直连，可以使用 NekoBox 的**路由规则**功能实现分流。点击顶部菜单栏的 **「设置」**，在 **「路由规则」** 标签页中添加自定义规则，例如：

| 规则示例 | 含义 |
| --- | --- |
| 目标域名 `target-website.com` → 走 IPWeb 节点 | 只有访问该域名的请求走代理 |
| 目标 IP 段 `10.0.0.0/8` → 直连 | 局域网地址不经过代理 |
| 默认 → 直连 / 其他节点 | 其余流量按需路由 |

这样只有匹配规则的流量才会通过 IPWeb 代理发出，其余流量保持原有路径不变。
