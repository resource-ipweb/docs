## 基础流程

### 1、注册账号

第一步，打开 IPWeb 官网 `https://ipweb.cc`，点击页面顶部导航栏中的「**注册**」按钮（已有账号的用户可直接点击「**登录**」）。

![IPWeb官网首页](https://oss.ipweb.cc/docs/imgs/2026/07/image1.png)

第二步，在注册页面填写你的**邮箱地址**和**登录密码**；也可以直接使用 **Gmail 账号**快捷注册（推荐），省去额外的密码设置步骤。

第三步，前往邮箱查收验证邮件，点击邮件中的**确认链接**完成邮箱验证。如果收件箱没有看到邮件，请检查垃圾邮件文件夹。（部分邮箱可能有延迟，耐心等待几分钟即可）

![IPWeb注册/登录](https://oss.ipweb.cc/docs/imgs/2026/07/image2.png)

### 2、领取试用流量

注册完成后，首次登录 IPWeb 用户后台 `https://user.ipweb.cc`，联系客服即可获赠 **免费试用流量**，体验全类型代理服务。

> 新用户可以先使用赠送流量测试代理效果，确认满足需求后再选择正式套餐。

### 3、购买代理 IP 套餐

成功登录 IPWeb 后，在左侧仪表盘选择你要购买的动态住宅代理。

动态住宅代理采用**按流量计费、随取随用**的模式，无需提前购买固定套餐，获取代理时即开始计量。

第一步，在用户后台左侧菜单中点击「**获取代理**」按钮。

第二步，设置以下参数：

- **国家 / 地区**：根据业务需求，选择代理 IP 的目标归属地（支持 220+ 国家）
- **代理服务器**：选定国家后，系统会自动为你分配对应的**代理服务器地址**
- **IP 持续时间**：指该 IP 的最长使用时间，时间一到会自动更换 IP。**IP 更换不会导致网络中断**，代理账号一直可用，只是 IP 会变。根据你的业务需求选择合适的持续时间
- **代理数量**：指导出代理账号的数量（比如需要 5 条就填写 5）。单次导出最大不超过 **1000 条**
- **代理协议**：HTTP 或 SOCKS5（根据客户端支持情况选择）

![动态代理参数配置](https://oss.ipweb.cc/docs/imgs/2026/07/image3.png)

第三步，首次生成代理时需要先**设置代理密码**——这个密码就是后续接入客户端时使用的认证密码。需要注意的是：**修改密码后生效时间约 1 分钟**；如果出现代理信息外泄或被盗，请及时修改此密码。

第四步，参数确认无误后点击「**生成代理**」，系统会自动下载一个 **txt 文件**。文件内容就是根据你的选择生成的代理连接信息，每行一条，格式为：

```
代理服务器地址:端口:用户名:密码
```

请妥善保存该文件，后续在 v2rayN 中配置时会用到。

| 支付方式 | 说明 |
|---------|------|
| 支付宝 (HK) | 港币结算，即时到账 |
| USDT-TRC20 | 加密货币支付 |
| 对公转账 | 企业客户可申请对公打款 |

在后台「**财务管理 > 充值中心**」中选择对应支付方式完成付款。企业客户如有定制化需求，也可直接联系客服获取专属报价方案。

> 动态住宅代理是按流量消耗扣费的，建议在充值后留意流量余量，避免因余额不足导致服务中断。


### 5、查看流量使用情况

购买完成后，你可以随时通过 IPWeb 后台对账户资产和使用数据进行可视化管理。

![仪表盘总览](https://oss.ipweb.cc/docs/imgs/2026/07/image5.png)

![流量历史记录](https://oss.ipweb.cc/docs/imgs/2026/07/image6.png)

#### 充值记录

点击「**动态住宅代理**」下的「**充值历史**」，这里详细记录了每一次为动态代理充值的**时间、单号、金额与状态**，方便财务核对与成本管理。

## v2rayN 配置 IPWeb 代理 IP

本教程针对 **v2rayN** 客户端编写。v2rayN 是一款基于 V2Ray 内核的 Windows 代理工具，支持 SOCKS5 / HTTP 等多种协议的代理接入。以下步骤以 **v2rayN 7.x** 版本为准（6.x 及以下版本操作路径类似）。

配置前请确保你已经完成了上一节的购买流程，并拿到了代理连接信息（代理服务器地址、端口号、用户名、密码）。

### 第一步：准备代理连接信息

确认你手上有以下四项信息：
- **代理服务器地址**
- **端口号**
- **用户名**
- **密码**

> 如果你购买的是**动态住宅代理**，这些信息就在你生成并下载的 txt 文件中；如果是**静态住宅代理**，在「已购线路明细」中查看。
>
> txt 文件每行格式为 `服务器地址:端口:用户名:密码`，可直接按顺序提取使用。

### 第二步：添加 HTTP / SOCKS5 代理服务器

打开 **v2rayN** 客户端，按以下步骤操作：

**① 通过「配置项」菜单新建服务器**

1. 点击顶部菜单栏的「**配置项**」。
2. 在下拉菜单中找到并点击「**添加 [HTTP]**」（如果你的代理协议是 SOCKS5，则选择「**添加 [SOCKS]**」），两者后续填写字段一致，仅协议类型不同。

![v2rayN 配置项菜单 — 选择添加[HTTP]](https://oss.ipweb.cc/docs/imgs/2026/07/v2rayn-step1.png)

**② 填写代理连接参数**

弹出窗口后，依次填写以下字段：

| 参数项 | 填写内容 | 说明 |
|-------|---------|------|
| **别名 (remarks)** | `proxy1` 或任意便于识别的名称 | 用于在节点列表中区分不同服务器 |
| **地址 (address)** | 你的代理服务器地址 | 来自第 3 节获取的信息（如 `gate1.ipweb.cc`） |
| **端口 (port)** | 你的端口号 | 来自第 3 节获取的信息（如 `7778`） |
| **用户名 (可选)** | 你的用户名 | IPWeb 代理认证账号 |
| **密码 (可选)** | 你的密码 | IPWeb 代理认证密码 |

其余字段（底层传输方式、传输协议等）保持默认即可，无需修改。

![v2rayN 填写代理参数 — 地址/端口/账密](https://oss.ipweb.cc/docs/imgs/2026/07/v2rayn-step2.png)

**③ 保存服务器**

确认以上五个关键字段填写无误后，点击「**确定**」。新添加的服务器会立即出现在 v2rayN 主界面的**服务器列表**中。

### 第三步：设为活动节点并测试延迟

**① 右键节点设为活动服务器**

在服务器列表中找到刚才添加的节点（如 `proxy1`），**右键点击它**，在弹出的菜单中选择「**设为活动**」（或直接双击该节点）。激活后节点名称旁会显示红色「**活动**」标记，表示当前选中状态。

同时你也可以在同一右键菜单中直接选择「**测试延迟 TcPing（多选）**」，快速检测该节点的连通性。

![v2rayN 右键节点 — 设为活动 & 测试延迟](https://oss.ipweb.cc/docs/imgs/2026/07/v2rayn-step3.png)

> 如果你有多个 IPWeb 代理账号需要管理，可以重复第二步逐一添加，之后根据需要在节点间切换即可。

**② 查看测试结果**

延迟测试完成后，服务器列表右侧的「**延迟 (ms)**」列会显示出具体的延迟数值（如 `353`）。只要能看到数值（通常在数百毫秒范围内），说明代理连接通畅。

![v2rayN 测试通过 — 延迟正常显示](https://oss.ipweb.cc/docs/imgs/2026/07/v2rayn-step4.png)

### 第四步：开启 Tun 模式并验证出口 IP

**① 开启 Tun 模式**

在 v2rayN 主界面**底部区域**，找到「**启用 Tun**」开关并将其打开（开关变为绿色即为已开启）。Tun 模式会接管系统所有网络流量，确保全部请求都通过你选中的代理 IP 发出。

![v2rayN 底部开启 Tun 模式 — 流量日志实时显示](https://oss.ipweb.cc/docs/imgs/2026/07/v2rayn-step5.png)

> 如果你只需要浏览器走代理而其他应用不走，也可以选择底部「**清除系统代理**」旁的下拉菜单切换为 PAC 或仅代理模式。但对于数据采集、账号运营等场景，建议使用 **Tun 模式**以确保所有流量统一出口。

**② 验证代理是否生效**

完成以上全部步骤后，用以下两种方式验证：

**方法一：浏览器访问 IP 检测网站**

打开浏览器访问 `https://ipinfo.io` 或其他 IP 检测网站，检查返回的 **IP 地址和归属地**是否为你所选购地区的代理 IP。

![IPinfo检测结果示例 — 显示代理IP归属地](https://oss.ipweb.cc/docs/imgs/2026/07/ipinfo-result.png)

如果显示正确（IP 归属地与选购的国家/地区一致），说明 **v2rayN 配置成功 ✅**。

> 如果 IP 检测显示的是你本地 IP，请按以下顺序排查：
> 1. 确认当前活动服务器是正确的 IPWeb 节点（列表中有红色「活动」标记的那个）
> 2. 确认「启用 Tun」开关已打开（绿色）
> 3. 确认填写的地址、端口、用户名、密码与后台信息完全一致（注意不要有多余空格）
> 4. 右键节点重新执行一次「测试延迟 TcPing」确认网络通畅
