# Hubstudio 指纹浏览器配置 IPWeb 静态原生代理教程

***在使用 IPWeb 代理服务之前，请确保您的网络环境可以正常访问境外资源。如遇连接问题，请检查本地网络或联系客服获取协助。***

IPWeb 提供全球 **7000 万+ 纯净住宅 IP**，覆盖 **220+ 国家/地区**，支持 HTTP/HTTPS/SOCKS5 三种协议，可满足数据采集、账号运营、广告验证等多种业务场景。

其中，**静态原生代理**能够提供稳定的固定出口 IP，更适合对网络环境连续性和连接稳定性有要求的业务。本教程将介绍从注册、试用、购买静态原生代理，到在 **Hubstudio 指纹浏览器**中完成 IPWeb 代理配置与连通性验证的完整流程。

## 基础流程 

### 1、注册账号

打开 IPWeb 官网 `https://ipweb.cc`，点击页面顶部导航栏中的[**注册**](https://user.ipweb.cc/console/sign-up)（已有账号的用户可直接点击[**登录**](https://user.ipweb.cc/console/sign-in)）。

进入注册页面后，默认可通过「**邮箱注册**」创建账号。依次填写账号 / 邮箱、邮箱验证码、密码和确认密码，点击「**发送验证码**」后前往邮箱查收验证码。填写完成后，勾选同意《服务协议》和《隐私政策》，再点击「**立即注册**」完成注册。也可以切换到「**手机号注册**」，按页面提示使用手机号完成注册。

![IPWeb邮箱注册页面](https://oss.ipweb.cc/docs/imgs/2026/09/ipweb-sign-up.png)

已有账号的用户可直接进入登录页面，通过账号 / 邮箱和密码登录；也可以切换到手机号登录。

登录页面下方同时提供「**以 Google 的身份登录**」入口，可使用 Google 账号快捷完成注册或登录，无需单独填写邮箱注册信息。

![IPWeb账号登录页面](https://oss.ipweb.cc/docs/imgs/2026/09/ipweb-sign-in.png)

### 2、领取试用流量

注册完成后，首次登录[ IPWeb 用户后台 ](https://user.ipweb.cc/console/sign-in)，联系客服即可获赠 **免费试用流量**，体验全类型代理服务。

> 新用户可以先使用赠送流量测试代理效果，确认满足需求后再选择正式套餐。

### 3、购买静态原生代理

登录 IPWeb 用户后台后，在左侧导航栏进入「**代理产品**」→「**静态原生代理**」→「**购买代理**」。

进入购买页面后，可根据使用需求选择 **独享** 或 **共享**，并选择是否开启「**自定义购买**」。

![IPWeb静态原生代理购买页面](https://oss.ipweb.cc/docs/imgs/2026/09/static-native-buy-proxy-custom-dedicated-steps.png)

购买时主要需要确认以下参数：

| 参数项 | 说明 |
| --- | --- |
| 独享 / 共享 | 独享代理由当前账户独立使用，共享代理使用共享资源池 |
| 国家 / 地区 | 选择需要的代理出口位置，可选范围以后台当前资源为准 |
| 业务用途 | 有特定使用场景时可按需选择，没有特殊需求可不选 |
| UDP | 根据实际使用的软件、协议和业务需求选择是否开启 |
| 带宽 | 选择当前代理实例所需的带宽规格 |
| 连接数（QPS） | 根据实际并发请求需求选择对应规格 |
| IP 购买时长 | 选择代理 IP 的服务周期 |
| IP 购买数量 | 填写本次需要购买的 IP 数量 |

如果关闭「**自定义购买**」，页面会切换为预设规格购买模式，带宽、QPS 和 UDP 等参数由当前套餐预设。

确认国家/地区、规格、购买时长、IP 数量及应付金额无误后，点击「**确认下单**」。系统生成订单后，选择页面支持的支付方式并完成付款。订单确认后，线路生成通常可能需要 **3–5 分钟**，请等待系统完成资源配置。

如需查看独享/共享、自定义购买、各项规格参数及支付流程的详细说明，可参考 [IPWeb 静态原生代理使用指南](https://docs.ipweb.cc/static-native-user-guide/)。

### 4、查看代理连接信息

静态原生代理购买并开通后，在左侧导航栏进入「**代理产品**」→「**静态原生代理**」→「**我的 IP**」，即可查看当前账户下已购买的代理资源。

![IPWeb静态原生代理已购IP查看页面](https://oss.ipweb.cc/docs/imgs/2026/09/static-native-my-ips.png)

在代理列表中，重点确认后续 Hubstudio 配置需要使用的信息：

- **IP**：已购买的静态原生代理地址；
- **端口号**：代理连接所使用的端口；
- **账号 / 密码**：连接代理时使用的认证信息；
- **使用状态**：确认当前代理资源处于可用状态。

页面还会显示国家/地区、带宽、共享/独享、连接数（QPS）、到期/续费、UDP 等信息，可用于核对当前代理资源。后续配置 Hubstudio 时，主要使用这里显示的 **代理 IP、端口号、账号和密码**。

如需了解代理筛选、账号导出、续费及其他管理操作，可参考 [IPWeb 静态原生代理使用指南](https://docs.ipweb.cc/static-native-user-guide/)。

## Hubstudio 指纹浏览器配置

完成上述流程并获取 IPWeb 的服务器地址、端口、用户名和密码后，即可将代理添加到 Hubstudio 浏览器环境中。

### 1、新建浏览器环境

打开 **Hubstudio** 客户端，在「**我的环境**」页面点击「**新建环境**」，进入浏览器环境创建页面。

![Hubstudio 新建浏览器环境](https://oss.ipweb.cc/docs/imgs/2026/09/hubstudio-image1.png)

根据实际使用需求填写环境名称等基础信息，然后找到「**代理信息**」配置区域。

### 2、配置 IPWeb 代理

在代理信息区域，将「**代理方式**」选择为「**自定义**」，然后根据上一节从 IPWeb 后台获取的代理连接信息完成配置。

| Hubstudio 配置项 | 填写说明 |
| --- | --- |
| **代理类型** | 选择与 IPWeb 当前代理对应的协议，例如 `HTTP`、`HTTPS` 或 `SOCKS5`。 |
| **代理主机** | 填写 IPWeb 提供的代理服务器地址。 |
| **代理端口** | 填写对应的代理端口。 |
| **代理账号** | 填写 IPWeb 提供的代理用户名。 |
| **代理密码** | 填写与代理账号对应的密码。 |
| **代理协议** | 根据当前代理实际情况选择。 |

例如，若从 IPWeb 导出的账号格式为：

```text
IP:PORT:USERNAME:PASSWORD
```

则对应填写关系如下：

```text
IP        → Hubstudio「代理主机」
PORT      → Hubstudio「代理端口」
USERNAME  → Hubstudio「代理账号」
PASSWORD  → Hubstudio「代理密码」
```

![Hubstudio 填写 IPWeb 代理信息](https://oss.ipweb.cc/docs/imgs/2026/09/hubstudio-image2.png)

> **注意：** Hubstudio 中选择的代理类型必须与 IPWeb 实际提供的代理协议一致。如果协议类型选择错误，即使服务器地址、端口和账密填写正确，也可能无法通过连接检测。

### 3、检查代理是否可用

代理信息填写完成后，点击「**检查代理**」。

如果检测结果显示「**连接测试成功**」，并能够正常获取代理出口 IP 及对应的国家/地区等信息，说明 IPWeb 代理已经成功连接到当前 Hubstudio 浏览器环境。

![Hubstudio 检查 IPWeb 代理](https://oss.ipweb.cc/docs/imgs/2026/09/hubstudio-image3.png)

此时可核对检测到的出口 IP 是否与 IPWeb 后台当前使用的代理信息一致。如果出口 IP 和目标地区符合预期，即可继续完成浏览器环境的其他配置。

### 4、保存并启动浏览器环境

代理检测通过后，继续完成浏览器环境的其他配置，然后点击「**完成**」保存。

返回「**我的环境**」页面，找到刚刚创建的环境并点击「**打开**」。浏览器启动后，该环境的网络请求将通过已配置的 IPWeb 代理访问目标网站。

如需进一步确认代理是否生效，也可以在当前 Hubstudio 浏览器环境中访问 `https://ipinfo.io` 或其他 IP 检测网站，检查当前显示的出口 IP 是否与 IPWeb 代理一致。

### 5、常见问题排查

如果 Hubstudio 中代理检测失败，可以依次检查：

| 现象 | 建议检查项 |
| --- | --- |
| 无法连接代理 | 检查代理主机和端口是否填写正确，并确认当前 IPWeb 代理仍处于有效状态。 |
| 提示认证失败 | 重新核对 IPWeb 提供的代理账号和密码，避免复制时带入空格。 |
| 检测一直超时 | 检查本地网络是否能够正常连接代理服务器。 |
| 已填写账密但仍无法使用 | 确认 Hubstudio 中选择的代理类型与 IPWeb 实际代理协议一致。 |
| 浏览器打开后显示本地 IP | 返回当前环境的代理信息，确认自定义代理已保存并通过「检查代理」。 |
| 检测地区与预期不一致 | 核对当前填写的 IPWeb 代理是否为所购买的目标国家 / 地区或城市节点。 |

> 不同 Hubstudio 版本的界面布局或按钮名称可能略有差异，请以当前客户端实际界面为准。请仅将代理用于合法合规的业务场景，并遵守目标网站的服务条款及当地法律法规。
